# 🐍 repo_python_util

Scripts úteis em Python para facilitar tarefas comuns, como conversão e verificação de charset.

## 📁 Conteúdo do repositório

Este repositório reúne pequenos scripts criados para uso próprio ou de suporte em tarefas recorrentes. Atualmente inclui:
| Script | Descrição |
|---------|------------|
| `verify_charset.py` | Verifica a codificação (charset) de arquivos de texto. |
| `xls_to_csv.py` | Converte arquivos `.xls` (Excel antigo) em `.csv`. |
| `xlsx_to_csv.py` | Converte arquivos `.xlsx` (Excel novo) em `.csv`. |

## 🧩 Por que usar:
- Automatiza tarefas repetitivas, como conversão de planilhas.  
- Evita retrabalho manual.  
- Simples de entender e estender.  
- Ideal para trabalhar com dados legados ou migração de arquivos.
